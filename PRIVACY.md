# PR Focus privacy policy

Last updated: 2026-11-23

PR Focus does not collect, transmit, sell or share any data.

- **What it reads.** On github.com pull request lists and pull request pages, it reads what the page already shows: each pull request's title, author, draft state and branch name, the signed-in user's login, and links to Linear issues. It uses them to decide which rows to hide and which Linear buttons to add. This happens inside your browser, and nothing is sent anywhere.
- **What it stores.** Your settings only: which rules are on, the title pattern, the Linear workspace and the team keys. They are kept in Chrome's sync storage, which Chrome syncs between your own browsers when you have sync turned on. The developer has no access to them.
- **What it does not do.** No network requests, no analytics, no tracking, no remote code, no GitHub or Linear token.
- **Linear buttons** are plain links. Opening one takes you to linear.app, where Linear's own privacy policy applies.
