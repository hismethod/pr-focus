The same choice as the buttons above the changed files (Alt+Shift+F switches it). Remembered for every PR. Sections also groups the file list on the left. The boxes below say what counts as noise.

*.test.*, *.spec.*, *_test.*, test_*.py, *Test.java, *Tests.swift, and the folders __tests__, test, tests, e2e, fixtures.

*.lock, package-lock.json, pnpm-lock.yaml, bun.lockb, go.sum.

Files GitHub marks as generated, *.snap, *.min.js, *.map, *.pb.go, *.generated.*, and the folders __snapshots__, dist, build, vendor.

Read like .gitignore lines: * stays inside a folder, ** crosses folders, a name without a slash matches at any depth, and a folder covers everything in it.
